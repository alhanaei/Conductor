# ChatGPT app setup notes

Use the canonical [common workflow](../../shared/WORKFLOW.md) and [bootstrap](../../shared/prompts/bootstrap.md). These are thin setup notes, not a copied master policy.

A general conversation, a connected project and a coding execution surface may offer different tools. Verify which source files and project repositories this session can actually read, whether it can write the exact authorized record, and how it receives instructions. Do not assume local Codex AGENTS.md or skill directory discovery applies to every ChatGPT conversation. If native discovery is unavailable, explicitly supply or retrieve the pinned shared procedure and project-owned task/checkpoint.

## Capability and adoption record
- Actual surface and version: unverified
- Read Conductor and project repository: verify source access
- Write project issue/PR/checkpoint: verify tools and authorization; otherwise return the standard record for an authorized recorder
- Execution environment and native discovery: verify separately if coding tools are available
- Tested/adopted practice release and immutable SHA: not adopted
- Last runtime verification and evidence: not performed
- Known limit: no assumed access to another app's private chat or universal vendor session controls
- Stable responsibility: follow the approved shared practice and report evidence; active assignments remain in project issues

For an actual Codex coding surface, consult the separate [Codex notes](../codex/README.md) and verify its documented paths. Configuration, access changes and publication require the appropriate authorization.
