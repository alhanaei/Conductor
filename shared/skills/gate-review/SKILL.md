---
name: gate-review
description: Review a project phase against its lifecycle gate and record the decision
---

Read [the canonical procedure](../../workflows/lifecycle.md) and [common workflow](../../WORKFLOW.md) at the project's adopted immutable practice version. This is a portable text wrapper, not an installed skill or authority grant. If these sources are unavailable, retrieve the verified version or stop dependent work; never invent the missing workflow.

Confirm the project-owned phase plan, the gate being reviewed, the owner and the reviewer (not the owner). Read the plan's outputs, the project checkpoint and the verification evidence. Answer the seven gate questions and the gate-specific addition with linked evidence, one line each. Return one outcome: pass; pass with conditions, each dated and owned; or hold with the specific failed criterion. An assistant may return the outcome for G0–G3; G4 and G5 require a human decider. Write the decision line to the phase plan's gate record and the project checkpoint only through supported authorized writes; otherwise return it as a standard update for an authorized recorder. A gate outcome never authorizes push, merge, release or deployment.
