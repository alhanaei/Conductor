Design authority: the shared-practice direction and the assistant-neutral kit, version
0.4.0-draft, verified by the root MANIFEST.json. The Claude Code templates are thin
references to the common workflow. The project adapter imports the project's vendor-neutral
`AGENTS.md` rather than duplicating project facts, so one filled project record serves
Codex, Claude Code and any other assistant that reads `AGENTS.md`.

Official format/discovery sources checked:

- [Memory and CLAUDE.md discovery](https://code.claude.com/docs/en/memory)
- [Skills](https://code.claude.com/docs/en/skills)

`{{UPPER_SNAKE_CASE}}` marks deliberate installation-time placeholders. Global fields bind
only a policy path/hash. Project fields bind the policy path/hash, source identity and the
checkpoint path; all other project facts stay in the imported `AGENTS.md`. The setup
example's `{{APPROVED_FULL_COMMIT_ID}}` is only usable after an approved commit containing
the kit exists. No secret values belong in these fields.

Verify `SHA256SUMS` from the kit directory using `shasum -a 256 -c SHA256SUMS` (macOS) or
`sha256sum -c SHA256SUMS` (Linux). After authorized publication, record the full containing
commit ID in each adopting project's installation record. Do not insert a self-referential
commit ID here or use a moving branch as a reproducibility pin. Updating any kit file
requires regenerated checksums, a regenerated root `MANIFEST.json`, and review.
