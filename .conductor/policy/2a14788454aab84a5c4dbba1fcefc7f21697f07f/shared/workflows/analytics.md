# Analytics workflow

1. Define the decision, audience, question and measurable outputs. Establish scope, authorized data sources, privacy boundaries and the task contract. Separate descriptive, predictive and causal questions.
2. Inspect source provenance, extraction time, snapshot/version, schema, units, currencies, time zones, observation grain, identifiers, row counts and coverage. Preserve original data; do not modify source systems. Document access gaps.
3. Validate missingness, duplicates, invalid types, impossible values, join cardinality, date boundaries and selection bias. Report row counts before and after each material filter/join. Resolve or explicitly document anomalies; never silently manufacture missing observations.
4. Define metrics before calculating: numerator, denominator, cohort, exclusion rules, aggregation level and time window. Avoid averaging ratios without justified weights. Distinguish zero from missing and nominal from real monetary values when relevant.
5. Build a reproducible script/query/notebook with pinned or recorded dependencies and random seeds where applicable. Keep raw sensitive data out of GitHub. Use approved private storage and save only authorized aggregates or sanitized fixtures.
6. Test calculations with small known cases and reconcile key totals against the original source or an independent calculation. Check data leakage, temporal splits, baselines, calibration and out-of-sample behavior for models. Use appropriate uncertainty and sensitivity checks; do not imply causation from association.
7. Create clearly labeled outputs with source dates, units, sample sizes, definitions and limitations. Inspect rendered charts/tables/files. Ensure dashboards do not expose row-level confidential data. State assumptions and distinguish evidence from interpretation.
8. Have an independent reviewer reproduce key results from the recorded input snapshot and exact code revision, challenge definitions and inspect transformations. Provide scripts, safe data references and a verification ledger, not only a polished report.
9. Deliver the decision-relevant findings plus reproducibility instructions, artifact locations, caveats and unresolved questions. Publication, sharing, production data writes and paid compute require explicit authorization. A private draft is not a published result.
